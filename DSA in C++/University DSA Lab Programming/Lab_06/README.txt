QUEUE ASSIGNMENT FILES

Source programs (C++17):
1. queue_array.cpp - fixed-size array queue (capacity 5)
2. queue_linked_list.cpp - dynamically allocated linked-list queue
3. queue_operations_practice.cpp - required sequence with state displayed after every operation

Compile an individual source file with g++:
  g++ -std=c++17 queue_array.cpp -o queue_array
  ./queue_array

Repeat for queue_linked_list.cpp and queue_operations_practice.cpp.
On Windows, run the generated .exe file rather than ./program.

The *-output.txt files contain stdout from the actual program runs. The *_screenshot.png files are terminal-style images made from that captured output and are also embedded in the DOCX/PDF report.
